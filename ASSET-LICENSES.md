# Asset provenance

All architectural geometry, SVG studies, procedural textures, visual composition and downloadable postcards are original artwork made for this fictional VELORA concept. Original artwork and postcards are released under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), attribution: “VELORA concept study, 2026”. Source code is MIT licensed.

No photography, stock media, generated paid images, external media services or paid APIs are used.

Fonts are bundled locally through Fontsource: Cormorant Garamond (Christian Thalmann and contributors) and DM Sans (Colophon Foundry and contributors), both under the SIL Open Font License 1.1. Exact license texts are in `licenses/`. No font requests leave the site origin.

React, React DOM and Three.js are open source MIT packages. Vite, TypeScript, ESLint, Playwright and axe-core are development/build/test dependencies with their respective open source licenses in the lockfile-resolved npm packages. No third-party UI component code was retrieved from the 21st catalog.
